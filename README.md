# 风驰卡丁车 · BREEZE KART

原创卡通 3D 浏览器赛车。在晴风海岸、秋名山道等九条赛道，与五位电脑车手完成三圈竞速，提供轻松至地狱五档难度。

## 直接游玩

双击 **index.html** 即可。解压后保持整个文件夹完整，包含 `vendor`、`js`、`css` 和 `assets`。

无需安装依赖、联网、账号或服务器。适用于支持 WebGL 2、已启用硬件加速的现代电脑浏览器；支持键盘与游戏手柄操作，未提供手机触控驾驶。

可选本地预览（需要 Node.js，无须 npm install）：

```sh
cd kart-racer
npm start
```

打开 http://localhost:5190。端口可使用 `PORT=5191 npm start` 更改。

## 操作

默认键盘操作；在右侧「怎么开？」切换到手柄模式后，使用标准映射（standard mapping）的游戏手柄驾驶，选择会在浏览器本地记住。

| 键盘 | 手柄 | 功能 |
| --- | --- | --- |
| W / ↑ | RT | 加速（手柄扳机深浅控制油门大小） |
| S / ↓ | LT | 刹车，停下后倒车 |
| A、D / ←、→ | 左摇杆 | 左右转向（摇杆推多少转多少） |
| Shift + 转向 | A / LB + 转向 | 速度达到约 50 km/h 后漂移集气 |
| Space | B | 使用氮气，持续约 2.3 秒，最多存两瓶 |
| Ctrl | X | 使用道具栏最左边的道具 |
| C | RB | 免费交换两个道具的顺序 |
| 长按 Q | 长按十字键 ↓ | 按住 0.6 秒丢弃首槽道具，松开取消，每次只丢一个 |
| R | Y | 返回有效赛道位置，短暂冷却，复位不增加圈数 |
| Esc | Start | 暂停 / 继续 |

键盘模式下手柄输入完全隔离，反之亦然，不会互相干扰。比赛中断开手柄会自动暂停。

道具无法使用时会说明具体原因（例如磁铁前方无目标、氮气已满），并保留原道具。换位和丢弃仅在比赛中可用；丢弃不释放攻击、不补发道具。使用或换位道具、复位、暂停、失焦、断开手柄、结束及返回菜单会取消丢弃进度，恢复后需松开再按。

### 手柄连接

支持标准映射（standard mapping）的手柄，包括 Xbox、PlayStation、Switch Pro 及兼容手柄：

1. 通过 USB 或蓝牙将手柄连接到电脑；
2. 按手柄上任意一个键唤醒（浏览器要求一次按键后才会识别手柄）；
3. 在右侧「怎么开？」切到**手柄**，状态显示「已连接 · 手柄型号」即可开赛。

无需切换回键盘的情况：暂停菜单和指南弹窗仍可用 Esc / Tab / 鼠标操作。

入弯时按 Shift（手柄 A/LB）配合转向：短按浅漂，持续按住加深漂移；同向调整弧线，反打方向或松开漂移键可拉正车头。反打结束后，松开再按漂移键即可开始下一次漂移。有效漂移出弯后保持油门，车身回正会自动触发一次短时小喷，不消耗氮气；碰撞、失控或驶出路面会取消奖励。不同弯道获得的能量会保留，集满得到一瓶氮气，空格（手柄 B）可独立释放。驶出路面会减速，护栏与车辆碰撞也会损失速度。

漂移时后轮会产生渐散的烟雾、轮胎辉光和连续胎痕，火花随集气从蓝色过渡到金色；集满氮气会触发金色火花迸发和“氮气就绪”提示。粒子使用固定容量循环复用，松开漂移后自然消散，暂停时冻结，复位和重开时清理残留特效。

按顺序通过检查点才能计圈；逆行不增加圈数，漏过检查点时按 R（手柄 Y）返回。离开窗口自动暂停并清空按键状态。个人最佳成绩、赛道、车身颜色、控制方式和声音开关在浏览器本地保存；浏览器禁止存储时仍可游玩。

## 实现

原生 JavaScript + Three.js 0.180.0，固定 60 Hz 驾驶更新，独立动画渲染。赛道使用闭合样条和等距采样；电脑基于前视路径、弯道速度规划和车道偏移驾驶。模型、道路、纹理和声音由程序生成，无远程资源或第三方跟踪。

Three.js 从 [官方 npm 包](https://www.npmjs.com/package/three/v/0.180.0) 构建为本地普通脚本，确保 `file://` 下可用。引擎许可位于 `vendor/three.LICENSE.txt`。Three.js 的安装方式见[官方文档](https://threejs.org/manual/en/installation.html)。

源文件职责：`tracks.js` 提供赛道配置；`core.js` 实现驾驶和比赛规则；`world.js` 构建与渲染场景；`kart-model.js` 构建车辆／车手及关节动作；`item-effects.js` 管理道具表现与对象池；`audio.js` 合成声音；`gamepad.js` 轮询手柄并映射为驾驶输入；`game.js` 管理输入、界面与本地成绩。`window.__kart.snapshot()` 提供只读诊断快照。

## 开发与验证

```sh
npm ci
npm run check
npm run check:tracks
npm test
npm run test:e2e
```

核心测试覆盖检查点、逆行、氮气、碰撞、暂停、排名、九条赛道电脑完赛与重开。浏览器测试通过真实键盘输入检查驾驶、漂移、加速、结算，并用实际渲染镜头验证方向键和 A/D 在普通驾驶、漂移时的左右转向；手柄测试注入模拟的 Gamepad API，验证模拟量驾驶、按钮动作、断开自动暂停与键柄双向隔离。另覆盖断网直接打开、存储受限、画面不支持与不同窗口尺寸。测试失败保留截图与 trace，HTML 报告在 `playwright-report`。

如测试机器没有 Playwright Chromium，先运行 `npx playwright install chromium`，或使用 `BREEZE_BROWSER_PATH=/path/to/chromium npm run test:e2e`。macOS 上也会识别已有 Playwright Chromium 缓存。

仅升级或重新构建内置引擎时运行 `npm run vendor`；正常游戏无构建步骤。开启系统“减少动态效果”会关闭装饰镜头摆动、加速视野扩张、漂移烟雾、火花和轮胎辉光，保留胎痕和静态集气提示；运行中切换该设置也会生效。

## 新版造型与渲染

六位车手共用科技风模型，保留三种玩家配色。道具包含金色六边形护盾、分叉闪电／持续电弧、水弹弧线、磁铁连线和飞碟光束。导弹命中后整车在 0.8 秒内前空翻落地，总眩晕仍为 1.1 秒；视觉动作不修改物理位置、碰撞或判圈。音效区分各类受击、持续状态与解除。

驾驶仍固定 60 Hz，画面和相机在相邻物理位置间插值，最多滞后一个物理步（约 16.7 ms）。内部渲染使用约 1920×1080 总像素预算，低配置自动降为约 1280×720；保持画面比例，界面文字不受三维分辨率影响。阴影贴图为 1024²，集中覆盖车辆附近；准备赛道时预编译效果材质。减少动态效果保留状态辨识，关闭腾空翻转等强动态表现。

本次更新保持独立 `file://` 运行、`breeze-kart-v1` 存档、历史纪录与键盘／手柄选择，无奖励授权或远程资源依赖。

## 性能复测

先运行 `npm start`，另一个终端使用 `node scripts/measure-frame-pacing.cjs`。脚本在隔离浏览器中以固定种子自动驾驶、禁用随机道具，使用 1920×1080 窗口与 1.5 设备像素比，预热后采样 12 秒。通过 `KART_PERF_TRACK=coast` 或 `neon` 选赛道，`KART_PERF_PHASE` 标记结果，`KART_PERF_ITEMS=1` 可增加每秒一次、固定顺序的道具压力场景，`KART_PERF_BASELINE` 可指定对比提交（例如 `66911723826d67c5193a118cdf74abbb91cfacf4`）。结果保存在 `output/performance/`。PowerShell 使用 `$env:变量名='值'` 设置变量。

测量需串行进行，不与浏览器回归或录像并行；记录实际 GPU、rAF 帧时间、JS 渲染耗时和画布尺寸。本机短时结果不代表所有设备；测试注入的驾驶／画面控制句柄不出现在生产代码中。

本次移植的兼容边界、测试记录与本机性能对比见[更新验收说明](docs/typing-upgrade.md)。
