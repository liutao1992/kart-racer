## 已整合

- 六车科技造型、独立模型／道具表现模块、分叉闪电、金色护盾、水弹弧线、磁铁连线、飞碟光束与导弹前空翻；保留配色及减少动态效果。

## 初次移植时的本机性能对比

以下为同步上游 `d551071` 之前的移植样本，基线为 `6691172`；并非最新漂移逻辑下的重新测量。

2026-09-07，Windows Chrome / ANGLE D3D11，Intel Iris Xe。固定种子 19419，1920×1080 窗口、设备像素比 1.5，实际连续驾驶并包含漂移。倒计时后预热 0.5 秒，采样 12 秒；每次独立浏览器，串行运行，不录制视频、不用 `gl.finish()` 干扰采样。压力场景每秒按固定顺序使用道具，两个版本采用相同注入规则。

内部渲染从 2880×1620 降为 1920×1080，并应用新版模型、特效与渲染优化。该对比评估整体升级效果，不能归因于某一个单独优化。

| 场景 | 帧时间 P95（前 → 后） | 超过 25 ms 的帧比例（前 → 后） | 超过 50 ms 的帧数（前 → 后） |
| --- | --- | --- | --- |
| 海岸连续驾驶 | 33.4 → 16.8 ms | 21.78% → 0.28% | 3 → 0 |
| 霓虹连续驾驶 | 33.4 → 16.8 ms | 13.69% → 0.14% | 7 → 0 |
| 海岸固定道具压力 | 33.5 → 16.8 ms | 22.55% → 0.70% | 7 → 2 |

新版三个样本均无 Long Task 或 WebGL／着色器错误。固定道具压力场景仍有两帧超过 50 ms，最慢 83.3 ms，因此不承诺完全无卡顿，也不将此短时样本推断到其他设备。与原版相比，场景中的帧时间 P95 和慢帧比例均改善。

原始 JSON 与截图在 `output/performance/`；复现方法见 README 的“性能复测”。本次不涉及部署；测量产物仅本地保存，不随源码提交。
